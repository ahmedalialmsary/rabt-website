# Preview & Deployment Rules

- **DO NOT** use temporary preview links or tunnel services (e.g. `localhost.run`, `ngrok`, `localtunnel`, etc.).
- For local preview: Use a standard local HTTP server (`python3 -m http.server`) for the user to open in their browser.
- For permanent live preview: Commit and `git push` after every fix/change to update the GitHub Pages live link.
- Permanent Live URL: https://ahmedalialmsary.github.io/rabt-website/
