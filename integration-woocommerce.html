تكامل إضافة ووكمرس الرسمية (RABT WooCommerce Gateway Plugin)

إضافة خفيفة وموثوقة لمتجر WordPress / WooCommerce تحول عملية الدفع والشحن في العراق إلى تجربة مؤتمتة ومطابقة 100% مع المحافظ الإلكترونية وأساطيل التوصيل.

تحميل الإضافة وتفعيل المتجر تجربة محاكاة checkout ووكمرس
متوافقة مع WooCommerce 8.0+ و WordPress 6.x

دعم التوقيع الرقمي المشفر HMAC-SHA256 والربط المباشر مع برمجيات الكاشير.

قدرات إضافة ووكمرس

لماذا يفضل مطورو ووردبريس إضافة رَبْـط؟

إضافة بوابات الدفع المحلّية

تأكيد السداد التلقائي لبوابات الدفع المحلّية العراقية والمحافظ الإلكترونية (مثل زين كاش، كي كارد، FIB وغيرها) بنسبة خطأ 0%.

مزامنة الـ Stock مع الكاشير

خصم الكمية من مخزون ووكمرس لحظة المسح الضوئي لكود الـ Barcode في كاشير المحل الفيزيائي (12ms).

أتمتة البوالص والمانفيست

توليد بوالص A6 وإرسال بيانات الشحنة لشركة التوصيل تلقائياً فور تحول الطلب إلى (قيد التجهيز).

هيكل الاستجابة لـ WooCommerce Webhook

هيكل بيانات ربط ووكمرس (WooCommerce Order Payment Webhook Payload)

POST /v1/webhooks/woocommerce/payment-complete WC_PLUGIN_VERIFIED 
{
  "plugin_version": "2.4.0-iq",
  "woocommerce_order_id": "WC-88401",
  "gateway_provider": "LOCAL_IRAQI_PAYMENT_GATEWAY",
  "payment_status": "COMPLETED_HMAC_VERIFIED",
  "sync_status": {
    "pos_stock_updated": true,
    "waybill_printed": true
  }
}
